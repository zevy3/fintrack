# Личный финучёт

Учебный full-stack проект (курс «Full-stack», МТУСИ, БПИ2401): учёт личных доходов и расходов,
категории, месячные бюджеты, отчёты и экспорт в CSV.

Стек: Python + FastAPI, PostgreSQL + SQLAlchemy, React + TypeScript, Git.

Подробное описание, запуск и модель данных появятся по мере выполнения лабораторных работ.
